# Sales Bonus — расчёт рейтинга продавцов

Скрипт на чистом JavaScript, который анализирует данные о продажах магазина: строит рейтинг продавцов по доходности и рассчитывает бонусы для каждого из них.

## Что делает программа

- Обрабатывает набор данных о продажах (товары, чеки, продавцы)
- Считает прибыль по каждой продаже с учётом скидок
- Формирует рейтинг продавцов по итоговой доходности
- Рассчитывает бонус для каждого продавца в зависимости от его места в рейтинге

## Особенности реализации

- Написано на чистом JavaScript без использования сторонних библиотек
- Логика расчёта прибыли и бонусов вынесена в отдельные чистые функции (принимают данные через аргументы, не обращаются к глобальным переменным, не имеют побочных эффектов) — это позволяет менять правила расчёта, не трогая основной код анализа

## Структура проекта

- `data/` — примеры наборов данных о продажах
- `src/main.js` — основная логика анализа
- `index.html` — точка запуска

## Как запустить

Открыть `index.html` в браузере и посмотреть результат в консоли DevTools (Ctrl+Shift+I).

Чтобы проверить работу на другом наборе данных, замените путь в `index.html`:

```html
<script src="data/dataset_1.js"></script>
```
